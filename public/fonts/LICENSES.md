# Font licences

Both families are self-hosted per `.claude/architecture.md` §7 — no Google Fonts
request, which would cost a third-party connection, a CSP entry and a privacy
question. Latin subset, variable, one file per family.

| File | Family | Licence |
|---|---|---|
| `outfit-latin-var.woff2` | Outfit | SIL Open Font License 1.1 |
| `jetbrains-mono-latin-var.woff2` | JetBrains Mono | SIL Open Font License 1.1 |

Both licences permit redistribution and embedding in a website. Retrieved from
the Google Fonts CDN on 2026-09-28; the files themselves are the upstream
releases, unmodified.
